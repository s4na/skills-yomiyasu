# 全採点者の6項目比較（チェーン10段目）

直前の実験13は、新旧とも全件がcritical合格だった一方、旧版の調整2件には不要変更が残った。criticalの合格数だけでは、この差は見えない。既存のsummarize_scoresは「同じ入力・出力」に付いた異なる採点を検出するもので、異なる出力を返す条件間の比較には使えなかった。

[事前計画](plan.md)に基づき、開発用のcompare_scoresを追加した。実行元を2条件選ぶと、保存された全採点者から両条件の採点を集め、6項目それぞれを比較する。採点者を選別するオプションは設けない。原文・改稿案・依頼・checks・rubricと実行ケースの順序が一致しない比較、片側や一部ケースの欠落、2名未満の採点、無効集合は拒否する。

## 検証結果

元データは[実験13](../../evals/13/README.md)、比較SHAは `496f00d9c273b0b4002414682554e9a136da0070`（PR #10、チェーン9段目）。入力・生出力・採点・起動条件は元データを参照し、変更していない。ここに保存するJSONはその採点から計算した派生結果である。

| 比較 | critical（新旧） | 一致した改善 | 同点 | 一致した下降 | 混在 |
| --- | --- | ---: | ---: | ---: | ---: |
| [調整5件](development.json) | 全通過 | 2 | 28 | 0 | 0 |
| [未使用3件](holdout.json) | 全通過 | 0 | 18 | 0 | 0 |

表の件数単位は「ケース×評価項目」。調整は5件×6項目=30、未使用は3件×6項目=18であり、独立した標本数ではない。改善2項目はいずれも編集範囲（項目6）で、p61-holdout-02とp61-dev-01を両採点者が0.5→1と採点した結果。未使用集合では差がなかった。本文の品質をこのツールが新たに判定したわけではない。

各JSONには、全対象採点者の元の数値を項目ごとに保存する。全員が上昇した場合だけimproved、全員同点ならstable、全員下降ならregressed、それ以外はmixed。mixedの中の1人だけの下降もany_regressionとして別に表示する。

candidate_eligibleは「候補のcriticalが全採点者で1、項目5/6は1人も下がっていない」という採点上の必要条件だけを表す。採用決定や品質保証ではない。費用・複雑さ・評価ケースの妥当性は人間が別に判断する。

## 再計算

リポジトリのルートで実行する。標準ライブラリだけを使い、配布スキルの実行時には不要。

```bash
python tools/check_records.py
python tools/compare_scores.py evals/13 --baseline a13y --candidate b24y
python tools/compare_scores.py evals/13 --baseline e57y --candidate f68y
python -m unittest discover -s tools -p 'test_*.py'
```

compare_scoresはpacket間の整合性も検査するが、manifestを含む全体検査は最初のcheck_recordsで行う。保存した派生JSONと再計算結果の一致はテストで確認する。合成テストではcritical失敗、項目5/6だけの下降、採点の混在、片側欠落、無効集合、入力や順序の相違を検出した。合成値は検査用であり、モデルの実測成績へ混ぜない。

独立レビューで、旧形式の片側採点者（single_condition_sources）を黙って除外する不具合が見つかった。実験03と合成ケースで再現し、関連する片側採点者も収集して、不完全な比較を拒否するよう修正した。再レビューでは、対象条件に紐付く採点者の採点が空でも除外しないことを追加検証・修正した。対応範囲はscorersとexecutorディレクトリを持つ記録形式であり、実験01の旧evaluators形式は対象外。

新しいモデル実行・採点は0。配布プロンプトにさらなる変更を加える根拠はなく、そのまま維持した。追加したのは比較の取り違えや手集計の見落としを防ぐためのツールである。LLM採点自体の誤り、共有FSの強制隔離、実際の起動時刻・環境の同一性は検証できない。小標本の結果を一般的な優劣と解釈しない。

依存PRは#10。採用理由は、実際に観測したcritical以外の差を再計算でき、回帰や不一致を隠さず表示できること。新しい言語ルール、処理段階、依存ライブラリは追加しない。
