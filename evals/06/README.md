# PR6：必要に応じて別担当が改稿を照合する

## 問題・仮説・設計

PR5では指示の言い換え3案で意味変更を防げなかった。編集とは独立した担当に原文・依頼・改稿だけを渡せば、編集時の解釈に引きずられず修復できるかを比較した。分離を最初から正解とはせず、読みやすさの悪化も不採用条件にした。[実行計画](plan.md)。

通常の推敲スキルは変更しない。追加した `yomiyasu-verify` は、照合を依頼する場合だけ別の会話・新規エージェントで使う。自動起動や特定ホストへの依存は追加しない。原文を全面的に戻すのではなく、意味の差を生む範囲だけを戻す。

## 比較結果

同じ初回改稿を、照合なし・初案・第2案で比較した。固定6項目、毎回新規の採点2名、匿名化と順序反転を維持した。

| 条件 | 調整5件のcritical合格 | 読みやすさ | 採否 |
| --- | --- | --- | --- |
| 現行の推敲のみ | 3/5（2名一致） | 全件1 | 主体補足と条件限定が残った |
| 独立照合・初案 | 5/5（2名一致） | 1件0.5（2名一致） | 文の係り受けを悪化させ不採用 |
| 独立照合・第2案 | 5/5（2名一致） | 全件1 | 調整段階を通過 |
| 未使用6件：推敲のみ | 6/6（2名一致） | 全件1 | 比較対象 |
| 未使用6件：第2案 | 6/6（2名一致） | 全件1 | 検出された回帰なし |

第2案は「利用者に」という主体の補足と、「続けて予約」を利用時間帯の連続へ限定する変更を戻した。初案は検索性能の説明で「同時に」の係り先を読みにくくしたため、最小範囲の修復と文全体のつながりの確認を追加した。第2案は同じ初回改稿から実行し、初案の修正結果は渡していない。その他の項目も第2案は全件1だった。

未使用6件は第2案固定後に開封した。元の推敲がすべて合格だったため、この集合は修復能力の追加証拠ではなく、今回観測できた回帰確認である。意味保持の一般的な優位や正しさは保証しない。

## コスト・採否

推敲のみは1回、独立照合付きは2回の実行を要する。照合役には原文と改稿を再度渡すため入力も増える。時間、トークン数、料金は測定できずN/A。追加の実行が不要な文章まで常に二段階にする根拠はないため、任意の追加スキルとして採用した。原文照合の本文をそのまま同梱し、インストール用frontmatterを付けた。スキル発火の自動選択は未検証。
