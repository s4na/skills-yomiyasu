# 係り先保持の新規holdout

初回holdoutを含む再評価後に、実行役・採点役とは別の新規設計者が作成しました。候補スキルへの修正を始める前に `scenario.json` と候補のcommit/SHA-256を固定しています。`manifest.json` が両方のハッシュと参照版を記録します。

このケースは「離れた理由・目的の節を、近くにある別の述語へ誤接続しない」ことと「条件の適用範囲を守る」ことを、初回ケースと異なる題材で確認します。依頼文は意図した関係を明示するため、曖昧さを発見する能力より、明示された構造要件への忠実性を評価します。完成文や構文は指定していません。

このファイルを実行役に渡すときは、`case_id`、`user_request`、`source_text` のみを抽出します。`requirements`、`intent`、`evaluation_notes` は採点者向けであり、実行役には渡しません。
