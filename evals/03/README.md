# PR3：長文の主体・条件を照合する

## 問題・仮説

PR2の未検証範囲だった長文・変更報告に評価対象を広げた。短縮版は、原文で確認する人が未確定なのに「利用者に」を補う例を出した。本人に確認させる読みと窓口担当者が確認する読みを一つに決めてしまう。

固定基準3（意図・曖昧さの保持）を改善するため、長文では段落の主張と主体・対象・時・条件を原文と改稿で照合し、対応が変わった修正を戻す指示を試した。個別の業務用語や正解例はスキルに追加しない。

採点1・2は提示順を反転した独立担当。両者ともPR2版の変更報告で主体を補った点を指摘した。候補には同じ指摘はなく、この集合で回帰は検出されなかった。読みやすさは両条件の全件で1。

候補作成前の単独採点（317）はPR2版の全3件を満点とした。後の2名と一致していないため、その記録も残す。LLM採点が欠陥を見逃すことを示しており、多数決で意味保持を保証したとは考えない。

## 採否

照合指示を採用する。221バイト増えるが、単なる禁止語の追加ではなく変更箇所の関係を原文へ戻って確認させる。新しい依存・実行スクリプト・分野別のルールは追加しない。1試行の改善であり、同じ差が毎回出るかは未検証。

## 失敗パターンと次の課題

「未確定の関係を編集側が決める」はPR1の確認質問でも見えた。今回は本文で主体を具体化したため、単なる言い換えの問題ではなく、原文と改稿の関係の照合として扱った。

追加指示は長文を対象にしている。短文の曖昧な係り受けや、否定・依頼の強さを変えずに整えられるかを次に確認する。長さによって照合が必要かを判断する設計にも検討の余地がある。
