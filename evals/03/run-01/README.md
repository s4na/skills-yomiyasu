- 参照: `nanaism/yomiyasu` v2.0.1、commit `84e1f5b15e497538fcfe19ab7e9c6f6d138f19ff`
- 修正前候補: commit `ffc4a972b4ac7324c90ffe26e93cd0524b8ab727` のスキル本文。実行スナップショットとSHA-256は [`baseline-SKILL.md`](baseline-SKILL.md) と [`../manifest.json`](../manifest.json) に保存
- 修正後候補: [`candidate-SKILL.md`](candidate-SKILL.md)。SHA-256は [`../manifest.json`](../manifest.json) に保存
- ケース: [`../scenario.json`](../scenario.json)。候補修正前に固定したSHA-256は [`../manifest.json`](../manifest.json) を参照
- 参照・修正前候補・修正後候補は、それぞれ別の実行役が1回実行。修正前と修正後候補の出力、参照出力と実行メモを保存
- 修正後の匿名出力を新しい採点者2名が独立評価。採点1は A=参照、B=候補。採点2は A=候補、B=参照
- 実行モデル名、tool_uses、duration_msは取得できずN/A

## 結果

- 修正前候補もこのケースでは「連絡を行います」を「連絡します」に直していた。したがって、このケース単独では修正前の実行挙動に失敗は観測されず、編集許可の記述と出力の不整合を示すものとなった。
- 修正後候補も「会議の開始時間が変更になったことを、参加者に連絡します。」と出力した。2名の採点者は、参照と候補の出力を同一文面として、両方の全要件を○、critical要件を全て合格と採点した。
- 修正は「自然に整えて」など表現自体の推敲を明示した依頼で、意味・関係・声を保つ最小限の語句・文法修正を許可する。これはそのような依頼に対する編集範囲の根拠を明文化するもので、修正前と修正後の出力差や一般的な品質向上を示す結果ではない。
- 1つの合成ケースによる確認であり、一般性能や利用者満足度は主張しない。
