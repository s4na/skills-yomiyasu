# skills-yomiyasu

意味と書き手の意図を保ち、読みにくい箇所だけを整える日本語推敲スキルです。

## 使い方

対応するエージェントのスキル配置先へ `skills/yomiyasu` をコピーし、推敲したい文章と依頼を渡します。

例：`$yomiyasu この社内連絡を読みやすくしてください。本文だけ返してください。`

実行用のスクリプトや外部ライブラリはありません。意味保持を保証する校正器ではなく、エージェントへの指示です。公開前には書き手が内容を確認してください。

### 改稿後に意味を照合する場合

追加の確認には `skills/yomiyasu-verify` を配置します。編集した会話を引き継がない別の会話または新規エージェントに、このスキルと次の3項目を渡してください。通常の推敲に自動で追加される処理ではありません。

```json
{"cases":[{"id":"a","request":"読みやすくし、本文だけ返してください。","input":"原文","draft":"改稿案"}]}
```

結果は `{"outputs":[{"id":"a","text":"照合後の本文"}]}` のJSONで返します。複数件も入力順に対応し、ケースごとの指定形式は `text` の中で守ります。追加の実行が1回必要です。調整用の比較では主体の補足と条件の限定を修復できましたが、毎回の修復を保証するものではありません。
