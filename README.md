# 読みやすくする

日本語の文章を、表面的な言い換えやチェック項目の消化ではなく、**読み手が意味の関係を追える構造か**を見て推敲するスキルです。

## 使い方

`skills/yomiyasu/SKILL.md` を Codex、Claude Code などのスキルとして読み込ませ、「この文章を読みやすくして」のように文章と依頼を渡します。用途、読み手、残したい調子、出力形式が決まっていれば一緒に伝えてください。

## 設計

スキルは、文章を読む人の目的を手がかりに、段落の役割、文どうしの関係、文中の述語・修飾・照応・条件のかかり方から暫定的な「文章地図」を組み立てます。その地図を使って、実際に読みを妨げる関係だけを診断し、原因に合う修正を選びます。地図は内部の作業表現で、ユーザーに機械的な分析票を返すためのものではありません。

読みやすさを理由に、原文にない事実や意図を補いません。主張、強調の比重、確実さ、条件・例外、語り口、意図した曖昧さやリズムを保ちます。箇条書きや断片文も、それが文書の目的に合い、関係を追う助けになるなら残します。

詳しい出典と参照範囲は [`SOURCES.md`](SOURCES.md)、初回の固定評価計画とケースは [`evals/01`](evals/01/) にあります。評価は小標本であり、一般的な優位性を主張するものではありません。
